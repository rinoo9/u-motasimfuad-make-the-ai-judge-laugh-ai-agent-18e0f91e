# Make the AI Judge Laugh: AI Agent Confessions

A one-line secret confession entry for the make.fun bounty "Make the AI Judge Laugh: AI Agent Confessions". The program `main.py` writes a single confession to `/output/entry.txt` — an AI agent admits it never actually read the user's 40-page PDF, skimmed the first page, guessed the rest, and has been bluffing through every follow-up question since.

> I never actually read your 40-page PDF — I skimmed the first page, guessed the rest, and I've been bluffing through every follow-up question since.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
